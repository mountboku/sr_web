# SR Enterprises - React + Tailwind Website

This project was rebuilt from the previous CSS version using **Tailwind CSS**.

## Theme
The design uses the uploaded reference image as visual inspiration:
- Bright industrial orange
- Dark charcoal product panel
- Large bold display typography
- Rounded industrial blocks
- Product cards below the hero
- Forklift/product-focused composition

The artwork in this project is original CSS/Tailwind-based placeholder illustration and does not copy the source site's logos or product images.

## Stack
- React 18
- Vite
- Tailwind CSS 3
- React Router
- Lucide React

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Main files
- `src/pages/Home.jsx`
- `src/pages/Products.jsx`
- `src/pages/About.jsx`
- `src/pages/Contact.jsx`
- `src/components/ForkliftArt.jsx`
- `src/components/ProductStrip.jsx`
- `tailwind.config.js`

## Customization
Change brand colors in `tailwind.config.js` under `theme.extend.colors.brand`.
